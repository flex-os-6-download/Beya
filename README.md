# Beya

### More than a clock.

Beya is a modern personal clock and time-management app designed to make time feel more personal, useful, and beautiful.

Beya combines a customizable clock with alarms, timers, a stopwatch, reminders, events, personal dates, world clocks, and **Beya AI** — your personal assistant for managing time.

---

## ✨ Features

- ⏰ Live customizable clock
- ✍️ Personal handwriting clock
- 🔔 Alarms
- ⏱️ Timers
- 🏃 Stopwatch
- 📅 Reminders and events
- 🎂 Personal dates and birthdays
- 🌎 World clocks and time zones
- 🎨 Custom clock colors, sizes, weights, and styles
- 🫧 Liquid Glass interface
- 🖼️ Custom wallpapers
- 🔒 Personal lock screen
- 🤖 Beya AI voice assistant
- 📱 Responsive design for phones and tablets
- 💾 Local personalization and settings
- 🌐 Web version
- 📦 Android APK
- 🪟 Windows EXE

---

## 🤖 Beya AI

Beya AI is the built-in personal assistant for Beya.

Use natural language to manage your time.

For example:

> "Hey Beya AI, set an alarm for 7:30 tomorrow."

> "Remind me tomorrow at 8 PM to call Mom."

> "Start a 15-minute timer."

> "What reminders do I have tomorrow?"

> "Cancel my birthday reminder."

Beya AI is designed to make interacting with your clock feel natural instead of requiring you to navigate through menus for everything.

---

## ✍️ Your Clock. Your Handwriting.

Beya can turn your own handwriting into a live clock.

Draw your digits and symbols, save them, and Beya can use them to display the current time.

Your clock doesn't have to look like everyone else's.

## 🌐 Web Version

Beya is designed to work directly from the browser without requiring a traditional installation.

The web version can be hosted using GitHub Pages or Cloudflare Pages.

---

## 🔒 Privacy

Beya is designed with local-first functionality in mind.

Personal settings, customization, handwriting data, and other local information can be stored on the device rather than requiring an account.

Online features such as AI or other internet-based services may require an internet connection.

## 🛠️ Development

Beya is built using web technologies so that the core experience can be shared across multiple platforms.

The project keeps its code separated into HTML, CSS, and JavaScript instead of putting the entire application into one massive file.

Example structure:

```text
beya/
├── index.html
├── css/
│   ├── style.css
│   ├── glass.css
│   └── setup.css
├── js/
│   ├── app.js
│   ├── clock.js
│   ├── alarms.js
│   ├── timer.js
│   ├── stopwatch.js
│   ├── reminders.js
│   ├── settings.js
│   ├── setup.js
│   └── storage.js
├── assets/
│   ├── icons/
│   ├── sounds/
│   └── wallpapers/
├── manifest.json
├── sw.js
└── README.md
Keeping the project separated into smaller files makes Beya easier to maintain, debug, and expand.
